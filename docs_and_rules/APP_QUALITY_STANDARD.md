# LV-DE Valodas Lietotnes Kvalitātes Standarts

1. TEHNISKĀ KONTROLE:
- Visiem datiem jābūt valīdā JSON formātā.
- Katrai kartītei obligāti ir unikāls ID (piemēram, "a1-an").
- ui.js nedrīkst saturēt tiešus teksta tulkojumus, tikai motoru un ikonas no konstantēm.

2. VALODNIECISKĀ KONTROLE:
- Vācu lietvārdiem OBLIGĀTI jābūt atsevišķam artikulam (der/die/das) un daudzskaitlim.
- Tulkojumos aizliegts izmantot semikolus (;), jalieto tikai punkti (•).
- Teikumu piemēriem jābūt dabiskiem. Ja vācu teikumā ir specifiska gramatika (piem., Akuzatīvs pēc "an"), tas ir jāpaskaidro sadaļā "explanation".
